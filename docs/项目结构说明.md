```
    └── latest_combined.log          # 整合的历史日志
```

## 使用流程

### 1. 数据集准备 (可选)
```bash
cd src
python prepare_lora_dataset.py
```

### 2. 训练 LoRA
```bash
cd src
python train_lora.py
```

### 3. 生成图片
```bash
cd src
python generate_lora.py
```

### 4. 评估模型
```bash
cd src
python evaluate_lora.py
```

### 5. 结果对比和可视化
```bash
cd src
python compare_100_vs_200.py
python plot_results.py
```

## 整理说明

本次整理完成了以下工作：

1. **目录重构**：将混杂的文件按功能分类到 src/、data/、models/、outputs/、docs/、logs/
2. **路径适配**：所有脚本更新为相对路径，可直接在任意环境运行
3. **冗余清理**：
   - 删除了重复的 generated_images_lora/ (148MB)
   - 删除了重复的 generated_images_sdxl/ (148MB)
   - 删除了 checkpoint-1000 和 checkpoint-2000 中的旧权重(共268MB)
   - 整合了分散的日志文件
4. **总计节省空间**：约 564 MB

## 注意事项

- 项目保留了所有重要的实验结果和数据
- 训练脚本中的 HuggingFace 镜像配置已保留
- 如需继续训练，运行前请确保磁盘空间充足
